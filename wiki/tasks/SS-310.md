# CLI favorites link support

## Summary

Extend the CLI's `add` command to accept a favorites share link as an alternative to
a repo URL ([FR-CLI10](../requirements.md#fr-cli10)). When the argument is a favorites link (detect by URL pattern,
e.g., contains `/shared/<token>`), extract the token and call SS-305's public read endpoint
to fetch the favorites list. Present the user with all repos/skills in the collection
for selection (same multi-select UI as normal repo install). Once selected, install each
skill using the normal flow (SS-502/SS-503). No telemetry for favorites-based installs —
this is a convenience feature, not a new data source.

**Example:** `npx skillstack add https://skillstack.app/shared/abc123xyz`

## Unit test requirements

- Given a favorites link argument, the CLI extracts the token and calls the public endpoint.
- The favorites list is presented for user selection (multi-select).
- Selected skills install using the normal file-writing flow (SS-503).
- Invalid or expired tokens show an appropriate error message.
- No telemetry calls are made for favorites-based installs.

## Integration test requirements

- The full command invocation → API call → selection → install flow works against
  a mocked backend response with multiple repos/skills in the favorites collection.
