# Share favorites link generator

## Summary

On the Favorites tab (SS-307), add a "Share" button that generates a shareable link
([FR-UI11](../requirements.md#fr-ui11)). Clicking the button calls SS-106's link generation endpoint via SS-305,
receives the token, and displays a full URL (e.g., `https://skillstack.app/shared/<token>`)
that the user can copy. The link points to SS-309's public favorites viewer. Show a
"copy to clipboard" helper and visual confirmation when copied.

## Unit test requirements

- Clicking "Share" calls the backend link generation endpoint.
- The returned token is formatted as a full URL for the public viewer route.
- Clicking "copy" copies the URL to clipboard (or simulates in test environment).
- Visual confirmation appears after successful copy.

## Integration test requirements

- The full click → API call → URL display → copy flow works against a mocked
  `@shared/firebase-cloude-api` response.
