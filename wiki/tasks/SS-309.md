# Public favorites viewer

## Summary

Create a public-facing route (`/shared/<token>`) that displays a user's shared favorites
collection ([FR-UI12](../requirements.md#fr-ui12)). No login required — anyone with the link can view. Fetches
favorites via SS-305's public read endpoint (`getFavoritesByLink`). Displays the same
layout as SS-307 (Favorites tab): full repo favorites show all skills, partial favorites
show only selected skills. Each item links to the repo/skill detail page. No edit/remove
capabilities (read-only view). Show a clear indicator that this is a shared collection
(e.g., "Shared by User Name" if available).

## Unit test requirements

- Page loads favorites via the public endpoint using the token from the URL.
- Invalid or expired tokens show an appropriate error message.
- Full and partial favorites render correctly (same layout as SS-307).
- Each favorite entry links to the correct repo/skill detail page.
- No edit/remove buttons are shown (read-only).

## Integration test requirements

- The full URL navigation → API call → render flow works against a mocked
  `@shared/firebase-cloude-api` response with both full and partial favorites.
- Invalid token handling displays error instead of favorites.
