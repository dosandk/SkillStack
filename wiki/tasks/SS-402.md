# Scheduled validation trigger

## Summary

A daily scheduled Cloud Function wrapping SS-401's validation service, per [FR-BE4](../requirements.md#fr-be4), implementing
the validation queue pattern ([AD-15](../architecture-invariants.md#ad-15), [FR-BE9](../requirements.md#fr-be9)): query all repos with `validationStatus: "pending"`,
load results into an in-memory array, then iterate. For each repo, SS-401 atomically changes
status to `"in progress"` before processing. This prevents multiple workers from processing
the same repo and gives visibility into stuck validations.

## Unit test requirements

- The scheduled function queries for repos with `validationStatus: "pending"`, loads them
  into an in-memory array, and processes each one (SS-401 changes status to `"in progress"`).
- Already-validated repos or repos with status `"in progress"` are not selected by the query.

## Integration test requirements

- The scheduled function, run against the emulator with a mix of pending/validated/
  in-progress repos, only processes the pending ones.
