# Favorite button UI

## Summary

Add a "favorite" button to the catalog (SS-104) and repository detail pages. The button
has two modes: favorite full repo (all skills) or favorite individual skill(s). Clicking
the button calls SS-305's `addFavorite` endpoint with the appropriate repoId and skillNames
array (empty for full repo, specific skills for partial) ([FR-UI9](../requirements.md#fr-ui9)). Show a visual
indicator (filled heart, star, etc.) when an item is already favorited. Button is only
visible/enabled when user is logged in (SS-201).

## Unit test requirements

- Clicking "favorite repo" calls the backend with `skillNames: []`.
- Clicking "favorite skill" calls the backend with `skillNames: ['skill-name']`.
- Button shows filled state when item is already in user's favorites.
- Button is disabled/hidden when user is not logged in.

## Integration test requirements

- The full click → API call → favorite-added flow works against a mocked
  `@shared/firebase-cloude-api` response.
- Favorites persist across page refreshes (read from backend on load).
