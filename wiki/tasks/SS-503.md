# Extract and write skill files from backend response

## Summary

Per [AD-7](../architecture-invariants.md#ad-7): once the backend's `scanRepository` response is received (from SS-501), extract
the file content from the response structure and write files to the local filesystem — the whole skill directory, any
sub-depth ([FR-CLI3](../requirements.md#fr-cli3)). No GitHub API calls; all file content is already included in the backend response
as base64-encoded blobs. Decodes content and writes to the appropriate platform-specific folder (from SS-502's selection).

## Unit test requirements

- Given a backend response with base64-encoded file content, the extraction function decodes and writes every file
  under the skill path (any sub-depth), matching [AD-6](../architecture-invariants.md#ad-6)'s "whole directory" rule.
- Binary files (images, etc.) are correctly decoded from base64 and written.
- A write failure for one file surfaces a clear error and does not silently produce a
  partial skill directory.

## Integration test requirements

- Processing a full backend response with multiple skills and mixed file types (text, binary)
  writes all files correctly to the local filesystem with proper directory structure.
