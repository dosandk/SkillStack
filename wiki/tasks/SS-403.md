# Validation results UI

## Summary

On the owner's own repository/skill view (reached from the profile page, SS-203, or the
favorites page, SS-307), display validation results: overall status (including `"in progress"` state while validation is actively running)
plus critical issues and non-critical recommendations as two visually distinct, structured sections
(never one paragraph of text — per [FR-UI7](../requirements.md#fr-ui7)). While validation is running, show an
`"in progress"` indicator so users know the check is actively happening.

## Unit test requirements

- While validation status is `"in progress"`, the UI displays `"in progress"` indicator.
- A response with critical findings renders them in a distinct "critical" section and
  shows an overall failed/blocked state (`valid: false`).
- A response with only recommendations renders them in a distinct "recommendations"
  section and shows an overall validated state (`valid: true`).

## Integration test requirements

- The full fetch → structured-results-render path works against a mocked
  `@shared/firebase-cloude-api` response with both severities present.
