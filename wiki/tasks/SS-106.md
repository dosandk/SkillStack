# Shareable link generation logic

## Summary

Implement the shareable link generation logic for the `userFavorites` collection. When
a user requests to share their favorites (via SS-308), generate a unique, URL-safe token
(e.g., nanoid or similar), store it in the user's `shareableLink` field, and return it
([FR-UI11](../requirements.md#fr-ui11)). The same token is used for all subsequent shares by that user unless
regenerated. The public read endpoint (SS-305) accepts this token and returns the favorites
without requiring authentication ([FR-UI12](../requirements.md#fr-ui12), [AD-14](../architecture-invariants.md#ad-14)).

## Unit test requirements

- Calling the generation function produces a unique, URL-safe token.
- The token is stored in the user's `shareableLink` field.
- Calling it again for the same user returns the existing token (idempotent) unless
  explicitly regenerating.
- The token is at least 16 characters to prevent guessing.

## Integration test requirements

- Generating a link against the Firestore emulator persists the token and allows the
  public read endpoint to retrieve favorites using that token.
