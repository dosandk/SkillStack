# Favorites tab UI

## Summary

Add a "Favorites" tab to the logged-in user's navigation (accessible from the main menu
or profile page). The tab displays all favorited repos and skills ([FR-UI10](../requirements.md#fr-ui10)). For each
favorite, show:
- Full repo favorites: repo name + all its skills listed
- Partial favorites: repo name + only the selected skills

Fetch favorites via SS-305's `getUserFavorites` endpoint on page load. Each item links
to the repo/skill detail page. From this page, user can also generate a shareable link
(SS-308) or remove favorites.

## Unit test requirements

- Page loads user's favorites via the backend on mount.
- Full repo favorites display all skills from that repo.
- Partial favorites display only the selected skills.
- Each favorite entry links to the correct repo/skill detail page.
- Removing a favorite calls the backend and updates the UI.

## Integration test requirements

- The full load → render → remove flow works against a mocked
  `@shared/firebase-cloude-api` response with both full and partial favorites.
