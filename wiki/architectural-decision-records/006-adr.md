## ADR-6 — Zod as the validation boundary and schema source of truth

**Status:** Accepted

**Context.** Untrusted input crosses the backend boundary and must be validated;
the same shapes are useful as TypeScript types.

**Decision.** Use **Zod** for runtime validation at the trust boundary (domain layer)
and as the single definition of persisted document shapes.
Test convention explicitly **forbids testing schemas themselves** — tests
cover the behavior of the function that consumes the schema, using valid input.

**Consequences.**

- Types and runtime validation are derived from one definition, preventing drift.
- `shared/` is the intended long-term home for schemas shared across packages;
