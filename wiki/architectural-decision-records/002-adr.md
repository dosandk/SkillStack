## ADR-2 — Firebase as the backend platform

**Status:** Accepted

**Context.** The project needs hosted compute, a database, auth, and static hosting
with minimal ops overhead, and a local story that reproduces production behavior.

**Decision.** Standardize on Firebase: **Cloud Functions** for the API,
**Firestore** as the system of record, **Firebase Hosting** for the built client
(`dist/`), and **Firebase Auth**.

**Consequences.**

- The whole stack runs locally through emulators, so integration and E2E tests
  exercise real Functions + Firestore rather than mocks.
- Hosting rewrites all routes to `/index.html`, making the client a true SPA.
- Deploys are gated: `firebase.json` sets `predeploy: npm run test:all`, so functions
  cannot ship without unit + integration tests passing.
- Lock-in to Firebase's data model and function runtime is accepted in exchange for
  the reduced operational surface.
