## ADR-8 — Vendored ELEKS UI design system, accessed only via aliases

**Status:** Accepted

**Context.** UI must be consistent with the ELEKS design system, which is MUI-based
and maintained outside a public npm registry.

**Decision.** Vendor the ELEKS UI component library into
`client/src/components/eleks-ui/` (`core/`, `x-components/`, `custom/`) and import it
**only** via the `@eleks-ui/components` and `@eleks-ui/theme` aliases — never by
relative path. `*.figma.tsx` files are excluded from the build. A dedicated `eleks-ui`
skill carries the full conventions.

**Consequences.**

- UI code depends on stable aliases, not on the vendored directory layout.
- Design-system upgrades are a controlled swap of the vendored tree.
- Raw MUI usage is discouraged in favor of the vendored wrappers.
