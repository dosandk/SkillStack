## ADR-10 — CLI built as a Commander app bundled with tsup

**Status:** Accepted

**Context.** `skillstack-cli` is a publishable command-line tool
that must ship as a runnable binary.

**Decision.** Build the CLI with **Commander** for command parsing, **chalk** for
output, and **tsup** for bundling to `dist/` (bin at `dist/bin.js`, exposed via the
`bin` field). It consumes the backend and GitHub strictly through `@shared`.

**Consequences.**

- The CLI is a second, independent consumer of the same gateway as the client.
- tsup produces a single distributable without a separate bundler config burden.
