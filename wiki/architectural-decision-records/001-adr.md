## ADR-1 — Single git repo, independently built packages (not npm workspaces)

**Status:** Accepted

**Context.** SkillStack has four codebases that ship on different targets — a browser
SPA, Cloud Functions, a published CLI, and shared library code. They need to evolve
together and share TypeScript types, but each has its own runtime, build tool, and
dependency set.

**Decision.** Keep everything in one git tree but give each package its own
`package.json` / `node_modules`, installed and built independently. This is **not** an
npm-workspaces monorepo. Cross-package TypeScript path aliases (`@shared`,
`@eleks-ui/*`) are centralized once in `tsconfig.base.json`.

**Consequences.**

- One clone, one PR can span client + backend + shared; types stay in sync.
- Each package picks the toolchain that fits it (Vite, tsc, tsup) without a shared
  build graph forcing compromises.
- Cost: dependencies are installed per package; there is no hoisting or single
  `npm install` at the root that provisions everything.
- Path aliases must be declared in **both** `tsconfig.base.json` and the relevant
  bundler config (`vite.config.ts`), because tsc and the bundler resolve separately.
