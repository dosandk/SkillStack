## ADR-7 — Persistence model: repository aggregate root + skills subcollection

**Status:** Accepted

**Context.** A repository contains many skills, and install analytics are tracked per
skill but must also be viewable per repository.

**Decision.** Store a **repository** as the aggregate root in the `repositories`
collection, holding metadata + a `skills[]` array. Each skill is **also** a document in
that repository's `skills` subcollection carrying an `installCount`. Install analytics
are per-skill counters aggregated onto the repository.

**Consequences.**

- Per-skill install counting maps to atomic counter updates on subcollection docs.
- Skill data is intentionally duplicated (array on the parent + subcollection docs) to
  serve both the browse read-path and the per-skill counter write-path efficiently.
